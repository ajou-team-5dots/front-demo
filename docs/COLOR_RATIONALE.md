# 몬스터 밸런스 대시보드의 그래프 색상

## 핵심 팔레트

| 색상 | 토큰 | 색상 사용 이유 |
| --- | --- | --- |
| 빨강 `#D15064` | `--chart-death` | 사망 집단과 높은 위험 구간에 쓴다. 경고 표시에서 익숙한 빨강을 쓰면, 여러 몬스터 중 먼저 살펴볼 대상을 찾는 단서가 된다. 상세 화면에서도 사망을 같은 빨강으로 표시해 개요에서 본 위험과 상세 수치를 연결한다. |
| 초록 `#53A653` | `--chart-survival` | 초록은 게임에서 회복이나 생명력을 표시할 때 익숙한 색이다. 처치에 성공한 교전이나 살아남은 교전에 이 색을 쓰면 사망 집단의 빨강과 짝을 이루어 두 결과를 구분하기 쉽다. 각 그래프의 범례에서 ‘처치’와 ‘생존’을 명시한다. |
| 남색 `#22448F` | `--chart-actual` | 선택한 몬스터의 값에 쓴다. 짙은 남색은 흰 패널에서 가는 선과 작은 점으로 그려도 또렷하다. 값이 높거나 낮아도 같은 색을 유지하므로, 특정 결과를 좋고 나쁨으로 판단하기 전에 관측값 자체를 읽을 수 있다. |
| 파랑 `#3B75E9` | `--chart-comparison` | 중앙값·평균·추정 범위에 쓴다. 관측값의 남색과 같은 파랑 계열이어서 두 값의 관계를 읽기 쉽고, 더 밝아서 기준선과 실제 데이터를 구별할 수 있다. 산점도에서는 이 색을 기대 수준과 2배 경계 사이의 점에 쓴다. |
| 밝은 주황 `#E0781C` | `--chart-accent` | Sankey에서는 파랑·초록 사이에 따뜻한 색을 더해 같은 열의 범주를 구별한다. 덤벨에서는 흰 배경과 옅은 눈금 위로 두 점 사이의 구간이 드러나게 한다. 가느다란 선에도 색이 남을 만큼 진한 주황이다. |
| 짙은 주황 `#B65B27` | `--chart-earth` | Sankey에서 주황의 따뜻한 인상을 유지하면서 밝은 주황과는 명도로 구분한다. 예를 들어 무기 열에서 ‘돌’과 ‘금·다이아’가 함께 나올 때, 두 칸에서 출발하는 띠를 서로 다른 농도의 주황으로 따라갈 수 있다. |
| 보라 `#B04FC0` | `--chart-violet` | Sankey의 중간보스에 쓴다. 몬스터 집단 열은 다섯 갈래이므로, 일반 몬스터의 파랑·초록·밝은 주황 및 던전 보스의 짙은 주황과 색조가 다른 보라를 더해 중간보스 경로를 찾기 쉽게 한다. |
| 청회색 `#9CA6B6` | `--chart-neutral` | 채도가 낮아 빨강·파랑보다 뒤로 물러나 보이면서도 흰 바탕에서는 점의 위치를 읽을 수 있다. 산점도에서는 기대 미만인 몬스터를, Sankey에서는 정해진 범주 밖의 값을 표시한다. |

## 그래프별 색상 적용

### 1. 메인 산점도 · 기대 대비 위험과 사망 수

| 요소 | 색상 | 색상 사용 이유 |
| --- | --- | --- |
| 기대 대비 2배 이상 | 빨강 `#D15064` | 빨강은 경고를 떠올리게 하고 주변의 파란 점·회색 점과 색조가 뚜렷하게 다르다. 점의 색으로는 2배 경계를 넘거나 경계에 닿은 몬스터에만 빨강을 써서, 많은 점 속에서도 먼저 확인할 대상을 골라낼 수 있다. |
| 1배 이상, 2배 미만 | 파랑 `#3B75E9` | 기대 수준에 도달했다는 차이는 회색보다 선명하게 나타내되, 빨강의 경고 의미는 2배 이상에 남겨 둔다. 이 때문에 1.9배와 2.1배가 가까이 있어도 서로 다른 점검 구간으로 읽힌다. |
| 1배 미만 | 청회색 `#9CA6B6` | 채도를 낮추면 낮은 위험의 점이 많이 모여 있어도 소수의 빨간 점이 묻히지 않는다. 점은 그대로 보여 전체 분포와 비교할 수 있다. |
| 우선 점검 구역과 2배 경계선 | 옅은 분홍 `#FDF1F2`, 빨강 선 55% | 사망 수가 중앙값 이상이고 위험이 2배 이상인 구역에 사망색을 흰색과 섞어 깐다. 면과 경계선이 빨간 점과 같은 뜻으로 읽히면서, 가장 진한 빨강은 개별 몬스터에 남는다. |
| 1배 기준선과 사망 수 중앙값 | 먹색 `#0B1220` 70%, 회색 `#4F5B6E` 60% | 기대와 같은 지점인 1배는 진한 가로 점선으로, 분포를 나누는 중앙값은 그보다 옅은 세로 점선으로 표시한다. 무채색이어서 위험 구간의 색과 경쟁하지 않는다. |
| 격자·라벨·가리킴 | 0선 `#BFC8D6`, 격자 `#E7ECF3`, 축 글자 `#4F5B6E`, 이름 `#0B1220` | 가는 격자는 옅게, 읽어야 할 이름은 진하게 두고 흰 테두리로 겹친 선에서 분리한다. 점을 가리키면 나머지 점의 불투명도를 40%로 낮춰 위험 구간의 색을 보존한 채 관심 대상을 드러낸다. 키보드 초점도 먹색 점선으로 표시한다. |

| 연결 띠 | 출발 칸 색 → 도착 칸 색 | 양 끝의 색이 각 칸과 일치해 띠가 교차해도 어느 칸끼리 연결되는지 따라갈 수 있다. |
| 띠의 강조 | 기본 35%, 가리킴 75%, 선택 85%, 관심 밖 8% | 범주색을 유지하면서 관심 경로의 농도만 높여 여러 띠 중 선택한 흐름을 쉽게 찾게 한다. |
| 이름·교전 수 | 먹색 `#0B1220`, 흰 테두리 | 흰 테두리가 글자와 띠를 분리해 여러 색이 겹친 곳에서도 이름과 수치를 읽기 쉽다. |
주황색에서 파란색으로 가는 색상 스펙트럼 변화에 맞춰 각 레벨 군집 별 색상을 정해 순서를 가늠하게 하고, 가장 높은 레벨군을 가장 짙은 색으로 구별한다. 이후 각 색상이 자연스럽게 흐름이 연결 지어져 보이도록 구성한다.

밝은 주황은 방어구 열에서 파란 ‘일부’, 초록 ‘6부위’ 옆에 놓여 ‘없음’을 별도 갈래로 구별한다. 레벨 열에서는 두 주황이 함께 나오므로 1~19는 밝게, 70+는 짙게 표시해 양쪽 경로를 구별한다. 같은 초록도 여기서는 열의 이름에 따라 ‘20~39’나 ‘6부위’처럼 읽는다. 조건의 뜻은 열 제목과 칸 이름이 정하고, 색은 같은 열 안에서 원하는 칸을 찾게 하며, 띠는 실제로 어떤 조건들이 이어졌는지를 보여준다.
### 3. 전투 양상 · 오각형 차트

| 요소 | 색상 | 색상 사용 이유 |
| --- | --- | --- |
| 몬스터의 외곽선·꼭짓점·면 | 남색 `#22448F`, 면은 18% | 다섯 꼭짓점을 같은 짙은 색으로 이어 한 대상의 윤곽으로 묶는다. 면에는 같은 남색을 옅게 깔아 도형의 넓이와 그 안을 지나는 기준 고리를 함께 볼 수 있다. 척도를 벗어난 꼭짓점에도 남색 점선 고리를 써서 같은 대상임을 유지한다. |
| 비교 집단 중앙값 고리·아래 눈금자의 0 표시선 | 파랑 `#3B75E9` | 고리와 0 눈금에 같은 파랑을 쓰면 눈금자의 중앙값을 도형에서 다시 찾기 쉽다. 남색보다 밝은 점선이라 두 윤곽이 겹쳐도 기준과 관측값을 구분할 단서가 남는다. |
| 눈금 고리·바큇살·축 글자 | 격자 `#E7ECF3`, 보조 회색 `#4F5B6E`, 먹색 `#0B1220` | 다섯 방향으로 반복되는 격자를 옅게 두어 몬스터의 윤곽이 먼저 보이게 한다. 가리킨 축의 바큇살만 진한 회색으로 바꾸고 다른 축 글자는 45%로 낮춰, 꼭짓점에서 해당 수치까지 시선을 옮기기 쉽게 한다. |

| 요소 | 색상 | 색상 사용 이유 |
| --- | --- | --- |

| **두 점을 잇는 가로줄** | **밝은 주황 `#E0781C` · `--chart-accent`** | 밝은 주황은 옅은 바탕선 위에서 실제 차이가 있는 구간만 드러낸다. 두 끝점과 다른 색을 쓰므로 선이 한 집단의 막대처럼 보이는 일을 줄이고, 여러 행에서 주황 선의 길이만 훑어 격차가 큰 조건을 찾게 한다. |
| 0~100% 가로 바탕선·세로 눈금 | `#E7ECF3` · `#E4E9F0` | 전체 폭은 가는 연회색 선으로 남겨 주황 구간의 길이를 판단할 기준을 제공한다. 세로 눈금도 옅게 두어 여러 행의 점을 같은 백분율 위치에서 비교할 수 있다. |
| 조건 이름·수치·표본 부족 | 먹색 `#0B1220` · 보조 회색 `#4F5B6E` | 집단별 수치는 진하게 써서 점이 가까이 놓여도 정확한 차이를 읽을 수 있다. 표본이 부족한 행은 회색 문구로 표시해 값이 있는 행의 점과 선에 시선이 머물게 한다. |
